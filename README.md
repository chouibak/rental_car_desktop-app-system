# RentalCar CRM

Application bureau (Windows) pour gérer une agence de location de voitures.

## Lancer l'application

```bash
npm install
npm run dev
```

Une fenêtre Electron s'ouvre avec l'app.

## Langues

- Français
- العربية (bouton FR / ع dans la barre latérale)

## Fonctions

- Tableau de bord
- Voitures
- Clients
- Contrats + paiements + retour véhicule
- Paramètres

Les données sont sauvegardées localement sur le PC (SQLite dans le dossier AppData).
